# Engineering Design website add-on

The complete ZIP contains the homepage, every prior project and `projects/engineering-design/`.

1. Copy the `projects` folder into the root of the existing `nneteteise.github.io` repository. Do not remove `.git`.
2. If the main homepage already has Engineering Design cards, avoid duplication; otherwise insert the contents of `ENGINEERING_DESIGN_ADD_TO_HOMEPAGE.html` before the `#about` section of `index.html`.
3. Open `projects/engineering-design/index.html` locally. Test GA3 gallery, GA8 gallery, GA11 editable budget/reset and all report links.
4. Commit and push with GitHub Desktop, then verify GitHub Pages.

The public-safe PDF reports retain all CAD images and group names but redact student numbers. Only the three supplied PDFs were available—native editable CAD files were not supplied.
