Temperature Controller Lab

Explore how a feedback loop turns simulated heating and cooling on or off. Change the target, watch the temperature and view the controller's history.

Educational reconstruction only: This browser demo uses a simplified thermal model and safe illustrative setpoints (22–38°C). It does not run the supplied Simulink file or interact with any real heater or fan. The report's 144°C simulation target is deliberately not used for this interactive model.

Controller behaviour

The heater activates below the target minus 2°C and deactivates above the target plus 2°C. In the demonstration, cooling is engaged above the upper threshold. The model includes simple heating, passive heat loss and fan cooling.
