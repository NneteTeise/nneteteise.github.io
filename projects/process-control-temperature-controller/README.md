# Process Control 2 — GA5 | Arduino-Based ON/OFF Temperature Controller

**Academic context:** PSC261S, 2026, CPUT, Group 15 (team contribution; Nnete Teise 20%).

This package contains a standalone showcase page with original report screenshots, a redacted PDF, the provided `.slx` model and a browser-only educational simulation. No real Arduino source code was supplied in the original project ZIP.

## Documentation limits
- The report lists an initial setpoint of 25°C in some places and 72°C in the simulation methodology, as well as 144°C for the simulated second setpoint. These are inconsistent; they are not presented as a confirmed physical prototype operating temperature.
- The actual `.slx` uploaded includes constant blocks 30 and 100 and basic control/scope blocks; it is not a complete reproduction of the hardware described in the report.
- Demo setpoints are deliberately restricted to 22–38°C as an illustrative UI and are not direct simulation results from the original work.
- The report's original numerical findings are reproduced as the team's claims, not independently recalculated.
- The public report copy removes five group-member student numbers and otherwise retains the original report.

## Viewing
Open `index.html` for explanation. Open `demo.html` for a static-hostable interactive demonstration. No backend or dependency required.
