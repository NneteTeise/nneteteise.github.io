Project overview

The uploaded GA_PowerSystems.slx model contains a three-phase power source, transformer, distributed-parameters line, measurements, an electrical load, a three-phase fault element, a breaker and a protection subsystem. The protection subsystem includes RMS measurement blocks, comparison logic and flip-flops. These represent a conventional rule-based protection design rather than verified machine-learning functionality.

3-phase source→Transformer & line→Fault & load→Measurements & relay→Breaker operation

Areas investigated

01 · Network modelling

Constructing a three-phase electrical power-system model with a transformer, transmission line, load and measurement points.

02 · Fault response

Comparing normal operating conditions with three-phase (LLL) and line-to-ground (LG) fault scenarios described in the companion analysis script.

03 · Protection logic

Examining RMS current measurements, threshold comparisons, latching logic and circuit-breaker operation.

Evidence and interpretation

What the files demonstrate: A saved Simulink model containing three-phase electrical-network and protection elements, plus MATLAB source code structured to compare currents, voltages and relay operating times. The files show technical modelling and an analysis workflow; they do not by themselves prove a successful rerun or validated protection times.
Data provenance: The MATLAB script first looks for Normal_run.mat, LLL_run.mat and LG_run.mat. If those simulation exports are absent, it reconstructs illustrative traces using fixed parameters and assumptions. Such fallback plots must not be presented as genuine Simulink measurements. Those .mat files were not included in this portfolio upload. The script comments call the work “AI-Based”, but no trained AI model is identifiable in the supplied files.

Technical reflections

The project connects electrical-machine and network modelling with protection logic and visualisation. A key engineering lesson is that transient plots and relay comparisons only become reliable evidence when their source-data files, breaker conditions, actual model parameters and timing measurements are recorded together. This page documents the available academic work and distinguishes it from subsequent reconstruction or interpretation.
