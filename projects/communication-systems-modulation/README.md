Practical experiments: AM, FM, ASK, PSK, FSK and PCM. The report also documents introductory MATLAB graph, calculator and matrix work.

- `source/COM261S_Communication_Systems_2_Public_Report.pdf`: the uploaded 21-page report converted to PDF with the student number removed.
