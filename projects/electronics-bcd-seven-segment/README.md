# Electronics: BCD (8-4-2-1) to 7-segment display

Academic project credits: **K Botsheleng and N. T. Teise** (collaborative work).

The supplied file was an 8-page PDF containing a truth table, Karnaugh maps, a Multisim schematic, Tinkercad screenshots (digits 0–9) and a photo of the physical prototype. Only a public-safe, student-number-redacted PDF is included.

Open `index.html` for the evidence page and `demo.html` for a fully offline browser reconstruction of the 0–9 active-high BCD truth table. The educational demo is not a real gate-level electrical simulator. Inputs 10..15 are invalid BCD and are blanked in the browser.

Original editable circuit files were not supplied, so none are claimed or linked.
