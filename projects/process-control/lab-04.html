Lab 04: Conveyor Motor & Box Counter

An HMI view of a conveyor with object sensing, timer and box tracking.

▶ Try interactive simulationDownload original TIA project (.zip)

What the system does

The HMI screenshots show motor ON/OFF indicators, a conveyor with a box, a timer field and a box counter. The exact object travel physics and full PLC state transitions are not fully recoverable from the screenshots.

Functional stages

  1. HMI displays motor ON/OFF indication and a conveyor graphic
  2. A proximity sensor and counter represent detected boxes
  3. Timer and count are exposed to the user on the HMI

Technology & evidence

Siemens TIA Portal project (.ap16) · PLC Ladder Logic · HMI for labs that include screenshots.
