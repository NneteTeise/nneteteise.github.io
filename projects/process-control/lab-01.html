Lab 01: Start/Stop Latching Circuit

A maintained run output using start, stop and seal-in logic.

▶ Try interactive simulationDownload original TIA project (.zip)

What the system does

The generic seal-in demonstration models a maintained RUN output after a momentary START action. Exact I/O labels and PLC scan behaviour have not been independently verified from the archived TIA project.

Functional stages

  1. Momentary START input establishes a RUN state
  2. Seal-in logic retains the output after START is released
  3. STOP breaks the run path and switches the output off
