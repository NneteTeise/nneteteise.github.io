# New GitHub Pages starter portfolio for Nnete Teise

This version includes the new homepage `index.html`, a Power Systems project cover and an individual project page.

**Use this option only if `nneteteise.github.io` does not yet have a homepage you want to keep.** Otherwise use the add-on ZIP so you do not overwrite existing portfolio content.

Steps:
1. Extract the starter ZIP.
2. Copy the contained `index.html` and `projects/` folder into the root of the local repository `nneteteise.github.io` using GitHub Desktop's **Show in Explorer** feature. Do not delete `.git`.
3. Preview `index.html` in a browser and click the project card.
4. Commit and Push origin in GitHub Desktop.
5. Under repository Settings → Pages configure `main` and `/(root)` only if not already configured. Published URL should be `https://nneteteise.github.io/` (unverified until deployed).

The MATLAB script contains fallback reconstructed waveforms, not genuine recorded Simulink results without matching `.mat` files. Do not claim machine-learning algorithms were implemented based only on the script heading.
