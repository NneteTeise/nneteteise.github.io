# Adding the Electronics project to Nnete's GitHub portfolio

## Recommended: complete website
- Extract the full portfolio ZIP.
- Copy the extracted **contents** into `nneteteise.github.io` (do not replace the `.git` directory).
- Open `index.html` and select **BCD-to-7-Segment Display Decoder**.
- Test `projects/electronics-bcd-seven-segment/demo.html` — click 0–9, toggle ABCD, click Auto count.
- Confirm the PDF report opens and evidence images load, then commit and push in GitHub Desktop.

## Project-only add-on
- Extract the add-on ZIP into your existing repository root.
- Paste the content of `ADD_ELECTRONICS_CARD_TO_HOMEPAGE.html` into the Projects section of your existing `index.html`.
- The site uses relative paths and needs no external JavaScript libraries.
