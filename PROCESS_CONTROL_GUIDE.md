# Nnete Teise — Process Control Labs (2026)

Included four ORIGINAL Siemens TIA Portal archives and extracted screenshots, plus NEW educational browser demonstrations.

Labs: 1 Start/Stop Latching; 2 Conveyor Object Counter (S_CU with target 10); 3 Star–Delta timer (10 s STAR then 20 s DELTA overload-timer behaviour); 4 HMI conveyor, sensor and box counter.

## Publishing
**Full starter site:** Copy all contents of the full-portfolio ZIP to the root of `nneteteise.github.io` if and only if you use the supplied starter homepage. The Power Systems project remains included.
**Existing custom site:** Copy only the `projects/process-control/` folder from the add-on ZIP, and add a link/card to `projects/process-control/index.html` in your existing homepage.

Preview `index.html` or `projects/process-control/index.html` locally. Test the simulator at `projects/process-control/simulator.html`, especially starting, stopping, resetting, detecting boxes, reaching a count of 10 and 10-second and 20-second timer transitions. Commit and push in GitHub Desktop to publish.

## Accuracy and privacy
The downloaded TIA Portal archives preserve the original files, including embedded student identifiers and program metadata. Consider whether to publicly expose them before sharing the repository. If you prefer, remove the `source` ZIP files and their links until the owner approves.
The browser simulation is a JavaScript teaching illustration, NOT a Siemens PLC emulator and NOT a real-world safety/functional test. The screenshots support the visible logic but do not establish a validated industrial system. Lab 1 had no standalone screenshot.

No deployment has been performed automatically; upload is a separate user action.
