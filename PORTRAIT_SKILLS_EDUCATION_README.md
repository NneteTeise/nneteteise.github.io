# Nnete Teise Portfolio — Photo, Grey/Blue Theme, Skills & Education Update

This update uses the latest complete Nnete portfolio package (including CV and existing project files) as the base.

## What's new
- Home hero now uses the supplied portrait as the cover background.
- Homepage and project-page CSS colour values were adjusted from green to blue/grey.
- New Skills tab and section, based on the supplied CV and existing portfolio projects.
- New Education tab and section, based on the supplied CV.
- All existing engineering project pages, source archives, demonstrations and CV are preserved.

## Publish with GitHub Desktop
1. Extract ZIP.
2. Open your `NneteTeise/nneteteise.github.io` local repository in Explorer via GitHub Desktop.
3. Copy the *contents* of this extracted ZIP into that repository; replace files as prompted. Do not delete `.git`.
4. Preview `index.html`, click Skills/Education and test project/demo links.
5. Commit (`Update portrait and grey-blue portfolio theme`), then Push origin.
6. Open https://nneteteise.github.io/ and hard-refresh (Ctrl+Shift+R).

## Privacy
The homepage displays the portrait supplied for this update. Confirm the portfolio owner approves its public publication. The existing public CV has its sensitive ID/street address information removed.
